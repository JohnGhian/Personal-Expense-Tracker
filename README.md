# Personal Expense Tracker

This is a simple Python project I built to practice managing data and working with files.

The program allows the user to record personal expenses, view them, calculate the total spending, delete an expense, and save the records to a CSV file.

## What It Can Do

- Add an expense
- View all expenses
- Calculate total expenses
- Delete an expense
- Save expenses to a CSV file
- Handle invalid amount inputs
- Use a simple menu system

   PERSONAL EXPENSE TRACKER
